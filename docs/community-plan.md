# Community plan

This project is early. The goal is to keep the scope practical and useful for developers building self-hosted attribution flows around WhatsApp, short links and automation tools.

## Near-term audience

- Developers building WhatsApp-first funnels
- n8n users who need attribution context
- Shlink users who want lead tracking
- Small teams that prefer self-hosted marketing infrastructure
- Agencies that need transparent campaign-to-lead tracking

## Useful contribution areas

- Deployment notes for different Cloudflare setups
- n8n workflow examples
- Shlink usage examples
- Dashboard SQL examples
- Meta CAPI and Google Ads conversion examples
- Tests for click and lead flows
- Security improvements for admin endpoints

## First outreach steps

- Share the repository with n8n and Shlink users.
- Ask for feedback from developers handling WhatsApp lead flows.
- Publish a minimal live demo with fake data.
- Keep issues small enough for first-time contributors.
- Avoid claims about adoption until there is real usage.

## Maintainer notes

The project should stay focused on attribution plumbing, not become a full CRM. Integrations should remain modular so teams can connect their own CRM, spreadsheet, queue or dashboard.
