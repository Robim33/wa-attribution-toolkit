# Changelog

## 0.1.0 - 2026-05-27

Initial public toolkit foundation.

### Added

- Cloudflare Worker API for WhatsApp attribution
- `/track` endpoint for click capture and redirect
- `/leads` endpoint for lead registration
- `/links` endpoint for tracked link creation
- `/stats` endpoint for basic operational visibility
- Cloudflare D1 schema for clicks, leads, tracked links and webhook logs
- Optional n8n webhook forwarding
- Optional Shlink short URL creation
- Open-source project documentation
