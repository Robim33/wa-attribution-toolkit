# Contributing

Thanks for considering a contribution to WA Attribution Toolkit.

## Good first contributions

- Improve documentation
- Add tests for click and lead flows
- Add n8n workflow examples
- Add dashboard query examples
- Improve Shlink integration
- Add deployment guides for real-world funnels

## Development workflow

1. Fork the repository.
2. Create a feature branch.
3. Make a focused change.
4. Run checks locally:

```bash
npm run check
```

5. Open a pull request with a clear summary.

## Pull request standards

A good pull request should include:

- Clear description of the problem
- Summary of the solution
- Testing notes
- Screenshots or logs when relevant
- No secrets, webhook URLs or real customer data

## Project principles

- Keep the core small and auditable.
- Prefer self-hosted and portable integrations.
- Avoid vendor lock-in.
- Make attribution data easy to move into CRMs, n8n, dashboards and data warehouses.
